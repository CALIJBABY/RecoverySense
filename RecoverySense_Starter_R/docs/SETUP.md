# Setup Notes

## Required tools

- Android Studio
- Visual Studio Code
- Flutter SDK
- Git / GitHub Desktop
- Firebase account
- Python 3.11+

## Optional later

- Xcode on macOS for Apple Watch support
- Docker for backend deployment
- Google Cloud / AWS for research backend

## Hardware

Recommended:

- Samsung Galaxy Watch 4 or newer Wear OS watch
- Refurbished Pixel or Samsung Android phone

Avoid watches that are not Wear OS if you need custom watch apps.
