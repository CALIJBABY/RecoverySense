# Start Here

Goal for this starter: get a running emulated phone app first.

Do not connect Firebase, watch data, or ML until the app runs.

## Commands

```powershell
cd apps\phone_flutter
flutter doctor
flutter pub get
flutter run
```

## First milestone

A successful Week 4 demo is:

1. App opens in Android emulator.
2. Login screen appears.
3. Continue button opens dashboard.
4. Dashboard shows mock HR and accelerometer data.
5. EMA screen opens and submits a mock answer.
