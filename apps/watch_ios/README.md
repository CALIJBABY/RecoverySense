# RecoverySense iOS / watchOS status

The active Android/Wear OS research prototype lives under `apps/phone_flutter_new` and `apps/wear_android/wear_android`.

The earlier placeholder Swift files in this folder were removed in v0.5.1 because they contained TODO-only sensor stubs and could be mistaken for an implemented Apple Watch client. A more developed iPhone/Apple Watch companion prototype is maintained as a separate development baseline and must be audited, versioned, and validated in Xcode before it is merged into this repository.

Do not report iOS/watchOS sensor collection as part of the validated RecoverySense build until that merge and device validation are completed.
