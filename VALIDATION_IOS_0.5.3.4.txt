EXPORT CRASH REVIEW
The archived report did not include a native iOS stack trace, so a single root
cause is not claimed. The source contained three concrete Apple-platform risks:
- potentially absent/invalid share-sheet popover origin;
- large ZIP compression on the Flutter UI isolate;
- immediate deletion of the ZIP after the share future returned.

The package adds:
- a non-zero sharePositionOrigin fallback;
- Isolate.run ZIP compression;
- application/zip MIME metadata;
- deferred temporary ZIP deletion with stale cleanup before the next export.
